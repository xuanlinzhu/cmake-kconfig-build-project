## Kconfiglib说明
Kconfiglib 是一个 Python 实现的 Kconfig 解析器和配置工具，常用于嵌入式系统中（如 ESP-IDF、Zephyr OS）。它提供了类似 Linux 内核的 make menuconfig 配置界面。menuconfig.py 是其提供的基于 curses 的图形化配置工具。
